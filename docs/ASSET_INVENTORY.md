## 新插图门禁

- 私有授权清单必须包含作品 ID、画师、Pixiv 原作页、许可文字、授权类型、主题、替代文本、本地源文件和授权证明引用。
- `pnpm artwork:import` 默认只检查；只有显式增加 `--apply` 才写入文件。
- 公开目录不保存授权聊天、邮件、本地源路径或其他私密信息。
- `pnpm assets:check` 检查目录和文件一一对应，并用 SHA-256 阻止图片被静默替换。
- 文章内容 schema 继续阻止 Pixiv/pximg 热链，并要求插图提供完整署名。
