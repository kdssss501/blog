用途：VELVET NOCTURNE 吸血鬼 VTuber 会客室的纯背景资产预览，作为 Web 页面全屏背景层；不是角色图、不是 UI 设计图，不包含任何人物、文字、徽标或控件。

画布：16:9 横向 2048×1152，正视图，适合 CSS background-image 覆盖并在 1920×1080 浏览器裁切。中心与左中部必须保留干净的 Live2D 人物安全空间，右侧保留一块较暗、低纹理的交流区背景，保证白色聊天文字可读。不要透视倾斜，不要设备边框。

空间：现代优雅的私人夜间会客室，黑色漆面墙、烟熏玻璃、高尖拱窗、窗外被薄云遮住的白色月光、两侧深酒红丝绒帘、哑光黑石地面、一盏窄冷银烛台、远处极少量深酒红花束。氛围成熟、安静、亲密、略带吸血鬼气质，不恐怖，不血腥，不做城堡插画。

色彩：煤黑、墨黑、骨白月光、冷银反光、深酒红丝绒，极少量低饱和青绿色反射。禁止蓝紫主色、赛博朋克、霓虹、HUD、雷达、网格、发光球体、bokeh blob、暖棕木屋、金色宫殿。

材质和光线：暗部有层次，窗光从后方柔和照入，烛火只在地面和银器上留下细小反射；丝绒纹理可见但不抢主体；地面有很淡的镜面反射与薄雾，不能把未来角色的脚部弄脏或隐藏。没有强烈光斑，没有镜头光晕。

动态友好：背景层应有可被前端分离的稳定区域：窗外月光、帘子、烛台、地面薄雾、右侧暗墙；整体构图允许 Live2D 人物位于左侧偏中、聊天区位于右侧。不要生成任何文字、角色、动物、蝙蝠或 UI。

输出要求：高精度 cinematic environment background，干净完整，无水印、无品牌、无伪文字、无人物，适合后续 CSS/Canvas 做轻微烛光、薄雾和窗光动画。
