用途：VELVET NOCTURNE 吸血鬼 VTuber 会客室右侧交流区的高精度局部设计稿。重点是优雅、亲密、可读和可长期使用的真实对话，不是手机聊天 App、不是科幻终端。

画布：4:3 横向，展示约 760×920 的完整交流区，四周留白 40px。煤黑背景 #0B0A0C、烟熏玻璃表面 #121114、骨白正文、冷银边线、深酒红重点、低饱和青绿色在线点。不要蓝紫，不要霓虹，不要暖棕金色。

结构：顶部 66px 角色头部；中段为可滚动消息正文；正文下方 42px 快捷意图行；底部 112px 输入区。外部不做独立圆角大卡片，只用一条冷银竖线表示它嵌入整页。

头部：左侧 38×38 方形角色头像占位，2px 圆角，旁边两行 “VAMPIRE” 与 “夜间在线”；在线点为低饱和青绿色。右侧依次是新会话、历史、清空三个 34×34 图标按钮。底边 1px 冷银 20% 透明线。不要重复的圆形头像环。

消息正文：消息最大宽度 76%，段落行高 1.65，间距 18px。吸血鬼消息靠左，深烟熏背景、左侧 2px 深酒红竖线、1px 冷银 14% 边界、4px 圆角；用户消息靠右，骨白 8% 透明底、1px 冷银 20% 边界、4px 圆角。每条上方只有 10px 等宽时间与情绪词，例如 “23:41 / CALM” 或 “23:42 / YOU”，不使用标签胶囊。

必须展示五种真实状态：欢迎消息精确写 “晚上好。今天想从哪里开始？”；用户消息精确写 “陪我聊聊今天发生的事。”；流式回复显示自然分段文本和 2px 宽、14px 高闪烁光标；引用回复底部有一行小号来源链接；错误状态左侧酒红警示线与文本 “连接暂时中断”，旁边有带刷新图标的 “重试” 按钮。文字清楚、不能被边线压住。

正在说话的消息底部放一条 120px 宽细银音频波形，随声音 RMS 起伏，不发强光。情绪只在时间旁显示 CALM、CURIOUS、WARM、CONCERNED 四种英文小词，并以 1px 下划线区别，不用彩色气泡。

快捷行：三个纯文字按钮 “听我说说”、“给我一个建议”、“安静陪我”，高度 42px，彼此用 1px 竖线分隔，选中态只改变文字颜色与底部 2px 酒红线，不做圆角块。

输入区：左侧麦克风图标按钮；中央两行无边框文字区，placeholder “说点什么…”；右侧 40×40 酒红发送箭头，流式响应中切换方形停止图标，尺寸不变。下方用 10px 等宽字显示 “ENTER 发送 · SHIFT+ENTER 换行”，颜色低对比但仍可读。

环境细节：右侧面板边缘能看到一小段深酒红丝绒帘和银色烛光反射；对话区不能出现雷达、网格、数据条、代码、HUD 或漂浮球体。材质是烟熏玻璃、黑色纸张和冷银蚀刻线，主要圆角最大 4px。

可访问性：焦点控件使用 2px 骨白外框并保留 2px 间距；禁用状态降低不透明度但不能只靠颜色；错误消息有图标和文字；文本高对比；所有按钮尺寸稳定。

输出要求：高精度真实 Web UI component screenshot，字体层级、间距、边界、流式、错误和输入状态清晰；中文英文准确，无乱码、无水印、无品牌、无额外说明。

避免：微信/Discord/WhatsApp 气泡风格、巨大头像、糖果色、胶囊标签、蓝紫赛博、霓虹、科幻雷达、卡片套卡片、手机竖屏、过度装饰。
