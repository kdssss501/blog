用途：桌面端 Web 应用整页视觉预览，直接进入一个可以长期交流的吸血鬼 VTuber 会客室，不是营销页、不是登录页、不是科幻控制台。最终需要能按 1920×1080 浏览器截图复刻。

核心概念：VELVET NOCTURNE / 绯夜会客室。一位成年吸血鬼 VTuber 在月夜私人房间里与访客交谈。SoulLink 的“灵魂”不是 HUD 数值，而是角色持续的呼吸、眨眼、注视、倾听、思考、说话和情绪细节，并让环境中的烛光、窗帘、薄雾和花瓣跟随她的状态微妙变化。气质优雅、亲密、成熟、安静，有一点危险感但不恐怖。

人物：左侧放一个原创、无品牌、无已知作品特征的成年女性吸血鬼 VTuber 占位角色，长银白发，黑色礼服与深酒红丝绒细节，少量冷银首饰，完整头到鞋尖可见，端庄自然站姿，面部清晰。她只是最终 Live2D 人物槽的视觉占位，不模仿任何现有角色、游戏、模型或品牌。不要幼态、不要暴露、不要血腥。

画布：16:9 横向 2048×1152，正视图，无设备外框、无浏览器外框。整页安全边距 28px。顶部极简导航高 54px，主体从 y=54 到 y=1020，底部控制轨高 66px。主体为左 61% 无框 Live2D 舞台、右 39% 交流区，中间只用一条 1px 冷银分隔线；不把整页切成一堆卡片。

整体空间：背景是黑色漆面与烟熏玻璃构成的现代哥特私人客厅，后方一扇高尖拱窗，窗外是被云层遮住的白色月光；两侧有深酒红丝绒帘，地面是哑光黑石，近处一盏窄银烛台。材质精致克制，暗部有层次，人物轮廓绝不融入背景。主色为煤黑、骨白、冷银、深酒红；在线提示只用低饱和青绿色。绝对不要蓝紫主色、赛博朋克、霓虹 HUD、雷达、网格、发光圆球、散景 blob、暖棕木屋或宫廷金色。

顶部栏：左侧显示细衬线字标 “VELVET NOCTURNE”，下一行极小字 “A PRIVATE CONVERSATION”；中间显示一条很短的酒红丝线与 “LIVE / LISTENING”；右侧依次是声音、弹幕、特效、全屏、设置五个 34×34 纯图标按钮。按钮只有 1px 冷银边界与 3px 圆角，悬停时变骨白，不使用文字胶囊。

左侧舞台：人物位于左栏中央略偏右，完整全身高度约占舞台 83%，脚下只有自然接触影。后方窗棂投下极淡银色影线；一圈很细的深酒红丝带状纹样绕在人物腰部以下，像房间装饰而不是魔法攻击。左下角是一小段不带数值的状态文字： “她正在听” / “她正在思考” / “她正在说话”，状态切换只改变字色和一条底线。人物周围有少量银灰尘粒与低速薄雾，不能遮住眼睛、嘴和手。

右侧交流区：不是传统聊天软件，而是一面嵌入墙面的烟熏镜面与黑色书写台。顶部有 38×38 方形头像、名称 “VAMPIRE”、副标题 “夜间在线”；右侧只有新会话和历史两个图标。正文以两种简洁的文字段落呈现：吸血鬼消息靠左，左边一条 2px 深酒红竖线；用户消息靠右，骨白 8% 透明底和 1px 冷银细线。最大宽度 76%，4px 圆角，消息之间留 20px。示例文字必须准确： “晚上好。今天想从哪里开始？” 和 “陪我聊聊今天发生的事。”。每条消息上方只放很小的时间与情绪词 CALM / WARM / CURIOUS，不做标签胶囊。

输入区：固定在右侧底部，高 110px，与消息区由 1px 冷银线分隔。左侧麦克风图标，中间两行无边框输入区，placeholder 精确为 “说点什么…”；右侧 40×40 酒红向上箭头发送按钮，生成中切换为方形停止图标，尺寸不变。输入区上方有三个细下划线快捷词： “听我说说”、“给我一个建议”、“安静陪我”。

底部控制轨：全宽，不做浮动卡片。左侧显示 “弹幕”、“字幕”、“声音” 三个带图标的开关；中间四个 36×36 表情图标对应平静、害羞、生气、难过；右侧显示 “夜间模式”和一个很小的模型状态点。所有控件尺寸稳定，文字不重叠。

SoulLink 生命感：平静时烛火每 4 秒呼吸一次，窗帘只摆动几像素；倾听时角色眼睛朝右侧交流区停留，窗上出现两道极淡声波；思考时烛光短暂变暗，薄雾从地面向上移动；说话时输入区上方出现随声音起伏的细银波形；温柔情绪出现 3 到 5 片深酒红花瓣，惊讶只有一次 160ms 白色轮廓闪光。效果低调、可循环、绝不满屏。

字体：中文用清楚的现代黑体，英文标题用优雅高对比衬线体，时间与状态用窄体等宽字。正文约 15px，标题不超过 24px，行高舒适。边界 1px，圆角最大 4px。不要大标题、不要解释性文案、不要把功能写成营销卖点。

输出要求：超精细真实产品界面截图，完整展示舞台、聊天、输入、状态和底部控制；中文与英文清楚准确，无乱码、无伪文字、无水印、无额外品牌。设计必须能由 HTML/CSS/Canvas/WebGL 实际复刻。

避免：蓝紫赛博朋克、科技网格、雷达圆环、科幻 HUD、霓虹紫光、卡片套卡片、渐变气泡、巨大人物海报、血液喷溅、獠牙特写、蝙蝠群、骷髅、恐怖城堡、幼态或暴露角色、额外人物。
