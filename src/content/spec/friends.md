## 🍀 本站信息

申请友链前请先在自己网站添加本站友链：

```yaml
站点名称: 我的博客
站点描述: 记录技术与生活的个人空间
站点链接: https://你的域名.com
头像链接: https://你的域名.com/avatar.png
```

## ✉️ 申请友链

请将你的网站信息发送至：`hello@example.com`

**邮件标题**：`友链申请 - [你的站点名称]`

**邮件模板**：

```
站点名称：[你的站点名称]
站点描述：[你的站点描述]
站点链接：[你的站点链接]
头像链接：[你的头像链接]
```

## ⚠️ 注意事项

1. 请先将本站添加到你的友链页面
2. 网站内容积极向上，无违法违规信息
3. 不允许含有病毒、恶意代码、弹出广告
4. 网站能正常访问，支持 HTTPS
5. 网站以原创内容为主
